# Code of Conduct

[日本語](../CODE_OF_CONDUCT.md) | English

Cerune is a personal project for learning about and experimenting with programming languages and compilers. Everyone participating in issues, pull requests, and reviews is asked to treat others with respect, regardless of experience or background.

## Expected behavior

- Discuss technical disagreements using code, observed behavior, and evidence.
- Respond considerately to questions from newcomers and to corrections.
- Describe bugs and proposals concretely, including reproduction steps when possible.
- Respect privacy; do not share personal information or material that has not been approved for publication.

## Unacceptable behavior

Personal attacks, discriminatory remarks, harassment, threats, repeated provocation, spam, and deliberate disruption are not acceptable. Criticism of an implementation is not a personal attack; hostility toward a person is.

## Scope and moderation

This code applies to public interactions related to this repository, including issues, pull requests, and reviews.

Depending on the situation, the maintainer may issue warnings, hide or remove comments, close threads, or restrict participation. As this is a personal project, continuous moderation and specific response times cannot be guaranteed.

You can also use GitHub's reporting features for inappropriate content. Do not post personal information or private conversations in public issues when reporting a concern.

Please report security vulnerabilities privately as described in the [Security Policy](SECURITY.en.md).
