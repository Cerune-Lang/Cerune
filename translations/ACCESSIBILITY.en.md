# Accessibility

[日本語](../ACCESSIBILITY.md) | English

Cerune aims to make its CLI and documentation accessible and easy to use for everyone.

## Our approach

- Provide clear, text-based CLI output and error messages.
- Use meaningful headings, descriptive links, and alternative text for images in documentation.
- Welcome feedback about accessibility barriers and improve the experience over time.

## Feedback

Please report accessibility issues or suggestions through [GitHub Issues](https://github.com/Cerune-Lang/Cerune/issues/new/choose).

Include the affected command or page, what was difficult to use, and your environment where relevant.

To contribute improvements, see the [Contributing Guide](../CONTRIBUTING.md).
