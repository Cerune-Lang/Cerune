引数取得・整数読取り・再帰・ファイルI/O・子プロセスは、HIR・MIR・SSA・VMおよび生成C・LLVM・QBE・WAT・Nativeで扱えます。実OSのファイルI/O・子プロセス接続はWindows/Linuxが対象で、WATでは版付きhostを使います。WATの関数公開はi32/f64の引数・結果に対応する初版です。

## 子プロセスと配布物

```text
Ceruneソース
  → std:processのRequestを作る
  → std:process::runのrunを呼ぶ
  → 共通runtimeが登録済みの対象を起動
  → Outcomeで終了状態・部分出力・失敗・回収結果を受け取る
  → 呼出し元の処理を続ける
```

`--process-config` で対象・作業場所・環境変数・容量と時間の上限を指定します。非0終了や起動・転送の失敗は結果値として扱えます。設定なしでは `Unconfigured` が返ります。結果値を作る領域自体が不足した場合などは、実行時診断で停止します。

生成C・LLVM・QBE・Nativeのリンクには静的runtimeを指定します。Linuxでは監督実行ファイルの絶対パスも設定します。WATは[参照host](../../experiments/wat_host/README.md)を利用できます。

配布手順にはコンパイラ5対象とruntime2対象のアーカイブ作成・展開後の実行試験を追加しました。runtimeにはヘッダ・ライセンス・manifest・SHA-256を添えます。対象は[試験したOSの一覧](release-readiness.ja.md#試験したos)で確認できます。

## 更新時の確認事項

| 対象 | 確認すること |
| --- | --- |
| 呼出し深さ | 既定128、`--call-depth-limit` は1〜128。ソース関数への呼出しを数え、引数評価後・関数へ入る前に検査。大きな局所値による物理stack/memory消費も考慮する |
| LLVM・QBEの生成 | スカラーだけのプログラムでも `--target` を明示する |
| 大きい・深いソース | [構文の深さ・ソース量の上限](../design/frontend-limits.ja.md)を検査し、超過を診断する |
| 浮動小数点 | 生成Cでも各乗算・加算の丸めを保持する。以前FMA収縮で差が出たケースは実行器と同じ結果になる。外部compilerのfast-math等の設定は[対応条件](../design/float-rounding.ja.md)を確認する |
| 整形 | `fmt` の既定出力はstdout。保存には `--write` または `-o` を指定する |
| 開発版の子プロセスimport | 旧表記 `std:process/run` を `std:process::run` へ置換する。関数・型・リンク要件は従来どおり |

子プロセスimportの変更は、v0.1.0公開後の開発版を使っていた場合の移行です。現在の書き方は次のとおりです。

```ceru
import "std:process" as types;
import "std:process::run" as process;
```

`types::Request` / `types::Outcome` と `process::run(request)` を使います。診断と `emit-sources` にも新しいモジュール名が表示されます。生成物・観測記録は利用する版で作り直してください。

## 実装・検証の改善

- Nativeの命令・データ・Object生成を、固定commitのSASHIMIへ移行しました。Ceruneから渡す命令と出自を引き続き観測できます。
- 入力の保存領域と確保失敗を、実行器・生成経路で比較するテストを追加しました。
- QBE 1.3取得は固定SHA-256で検査し、配布元に接続できない場合の検証済み取得先を追加しました。
- Windows/Linux/macOSのCI、配布アーカイブの実行試験、依存関係の検査を整えました。開発用Rustは1.98.0、Node.jsは24を使用します。

## 試す

この版を含むソースのリポジトリルートで実行します。

```sh
cargo run --quiet -- run examples/recursion/factorial.ceru
cargo run --quiet -- run examples/arguments/seed.ceru -- 1 3
cargo run --quiet -- run examples/process_execution/unconfigured.ceru
cargo run --quiet -- fmt examples/formatting/infer.ceru --let hide
```

階乗は `120` と `1`、seed例は `48271`・`182605794`・`1291394886` を出力します。子プロセス例は未接続の結果と `continued` を表示します。最後のコマンドは整形したソースを表示します。
